# 앱인토스 콘솔 등록 내용 (복사해서 붙여넣기용)

콘솔(https://console-apps-in-toss.toss.im 또는 개발자센터 안내 링크)에서 "앱 정보 등록" 화면에 아래 내용을 그대로 넣으면 됩니다.
`[ ]` 표시는 본인 값으로 바꾸세요.

---

## 3. 상세 소개

검수팀은 "사용자가 처음 실행해서 핵심 기능을 경험하기까지의 흐름"을 보고 싶어 합니다. 그 순서대로 썼습니다.

```
계란, 삼겹살, 쌀, 양파, 대파, 사과, 배추, 닭고기. 장 볼 때 자주 담는 품목의 오늘 가격을 어제와 비교해 보여줍니다.

한국농수산식품유통공사(aT)가 매일 조사해 공공데이터포털에 올리는 소매가격을 그대로 씁니다. 마트 생필품 탭에서는 한국소비자원 참가격이 격주로 조사하는 라면, 우유, 화장지, 세제 같은 생필품 330여 개의 매장별 가격을 비교할 수 있고, 식품의약품안전처의 회수·판매중지 식품 정보도 함께 보여줍니다. 서울이 기본이고 부산, 대구, 인천, 광주, 대전, 울산으로 바꿔 볼 수 있습니다. 많이 사는 품목이 위에 오고, 그 아래로 채소, 과일, 축산, 수산 전체 품목이 이어집니다.

품목을 누르면 그 자리에서 최근 1주 가격 흐름이 펼쳐지고, 상세 화면에서는 1개월 추이와 어제, 1주 전, 1개월 전, 1년 전, 평년 비교표를 볼 수 있습니다. 자주 확인하는 품목은 즐겨찾기로 등록하면 목록 맨 위에 고정됩니다.

로그인 없이 바로 쓸 수 있고 개인정보를 수집하지 않습니다. 가격은 조사 결과를 그대로 전달하는 것이며 매장과 지역에 따라 실제 판매가는 다를 수 있습니다.

출처: 한국농수산식품유통공사 농산물유통정보, 한국소비자원 참가격(이상 공공데이터포털, 공공누리 제1유형), 식품의약품안전처 식품안전나라
```

## 4. 검수팀에게 남기는 메모 (검토 요청 시 "메모/특이사항" 란)

```
- 데이터 출처: 공공데이터포털 한국농수산식품유통공사 지역별 소매가격 API, 한국소비자원 참가격 생필품 가격 API(이상 공공누리 1유형), 식약처 식품안전나라 회수·판매중지 정보. 앱 하단과 상세 화면에 출처를 표기했습니다. 사용자 조회 시 외부 API를 호출하지 않고 하루 2회 배치로 저장한 JSON 만 읽습니다.
- 로그인·결제·외부 링크 없음. 외부 요청은 정적 JSON(HTTPS, GitHub Pages) 뿐이며 외부 페이지를 로드하지 않습니다.
- 광고: 하단 고정 배너 1개(리스트 화면), 전면형(상세 진입 10회당 1회), 보상형(즐겨찾기 칸 확장·다른 지역 24시간 열기, 시청 완료 시에만 보상. 서울은 항상 무료).
  같은 화면에 같은 포맷 광고는 1개이며, 광고 클릭에 보상을 주지 않습니다. 테스트 광고 ID는 모두 실제 광고 그룹 ID로 교체했습니다.
- 뒤로가기: 안드로이드 backEvent를 구독해 상세/설정 → 리스트 → 종료 순으로 동작합니다.
- 금융상품·투자 정보를 다루지 않으며, 농축수산물 소매가격만 표시합니다.
```

## 5. 아이콘

- 규격: 600 × 600 px, PNG, 배경색 필수(투명 불가), 모서리 각진 정사각형(둥근 모서리 불가)
- `docs/icon-600.png` 는 임시 아이콘입니다. 그대로 써도 심사에는 문제 없지만, 원하면 Figma/Canva에서 같은 규격으로 만들어 교체하세요.

## 6. 스크린샷

- 세로형 636 × 1048 px PNG **최소 3장** (가로형 1504 × 741 px는 1장 이상, 있으면 좋고 없어도 됨)
- 찍는 방법: 토스 앱 샌드박스(QR)에서 실행 → 기기 스크린샷 → 636×1048 으로 리사이즈(비율 유지, 여백은 배경색으로)
- 권장 3장: ① 메인(상승·하락 5 + 많이 사는 품목) ② 마트 생필품 탭(체인별 평균·가장 싼 매장) ③ 품목 상세(1개월 추이)
- 스크린샷에 **테스트 광고**가 찍히면 안 됩니다. 실제 광고 ID로 바꾼 뒤 찍거나, 배너 영역이 안 보이게 자르세요.

## 7. 개인정보 처리방침 / 이용약관

- 콘솔에 URL 입력란이 있으면 `docs/privacy-policy.md` 를 GitHub Pages에 올린 주소를 넣으세요.
  (예: `https://github.com/know77701/toss_app/blob/main/docs/privacy-policy.md` — 워크플로가 `out/` 에 함께 올리도록 하려면 README의 "개인정보 처리방침 게시" 항목 참고)
- 이 앱은 개인정보를 수집하지 않으므로 내용은 짧습니다.

## 8. 광고 그룹 (콘솔 › 인앱 광고)

| 광고 그룹 | 포맷 | 용도 | .env 키 |
|---|---|---|---|
| todaymarketprice-banner | 배너(리스트형) | 리스트 하단 고정 | `VITE_AD_BANNER_ID` |
| todaymarketprice-interstitial | 전면형 | 상세 진입 5회당 1회 | `VITE_AD_INTERSTITIAL_ID` |
| todaymarketprice-rewarded | 보상형 | 즐겨찾기 칸 +3, 다른 지역 24시간 열기 | `VITE_AD_REWARDED_ID` |

광고 그룹 ID가 구글에 등록되기까지 최대 2시간 걸립니다. 만들고 바로 테스트하면 "no fill"이 뜰 수 있어요.
